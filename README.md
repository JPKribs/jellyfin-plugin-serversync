![Server Sync](Jellyfin.Plugin.ServerSync/Assets/Logo.png)

A Jellyfin plugin that keeps several Jellyfin servers in step. It syncs **Content**, **Watch History**, **Metadata**, **People**, **User Settings**, and **Playlists** across servers, on a schedule and, between servers that both run the plugin, as changes happen.

## Documentation

Installation, setup, every sync type, and the API are covered in the **[Server Sync documentation](https://jpkribs.github.io/jellyfin-plugin-serversync/)**.

Plugin repository URL for Jellyfin:

```
https://raw.githubusercontent.com/JPKribs/jellyfin-plugin-serversync/master/manifest.json
```

## Use At Your Own Risk

This plugin modifies live data on your Jellyfin server. While extensively tested, I maintain this plugin for my personal use case and I do not account for every server configuration. **Always maintain backups of your Jellyfin data and configuration.** By using this plugin, you accept full responsibility for any data loss or issues that may occur.
